Como Contribuir

O Ensaio de Dança é um projeto de código aberto mantido nos fins de semana. Você pode ajudar mesmo sem programar!

1. Criar poses e coreografias

As poses ficam em src/data/poses/catalog.json e usam até 8 ângulos de braços e pernas. Você pode usar o gravador do próprio jogo para testar ideias novas e enviar um PR.

2. Compor músicas livres

Queremos ampliar as músicas públicas com faixas sintetizadas em código (Web Audio) ou músicas originais doadas sob licença CC0 / CC BY 4.0.

3. Testar em aparelhos diferentes

Testar o modo offline, a câmera frontal e a orientação horizontal em diferentes modelos de Android e iPhone ajuda muito a manter o jogo fluido.

4. Código, acessibilidade e traduções

Melhorias de contraste, leitor de tela, desempenho em celulares antigos e tradução da interface para inglês e espanhol estão entre as prioridades.

Regras de ouro do projeto

  • Nada de conteúdo protegido de terceiros: PRs com áudio, letra, imagem, personagem ou logotipo de terceiros são recusados.
  • Privacidade inegociável: nenhuma dependência de analytics, CDN externa ou envio de dados sem passar pela Política de Privacidade.
  • Tom positivo: toda mensagem para a criança é encorajadora e a nota mínima é sempre 1 estrela.
  • Sem fotos ou vídeos de pessoas reais: nos testes e nas issues, use sempre o modo simulado (?sim=1).

Rodando no seu computador

npm ci
npm run setup:mediapipe
npm run dev          # abre o site em / e o jogo em /jogar/
npm run check        # tipos, lint, testes de unidade e build
npm run test:e2e     # testes ponta a ponta no Playwright

Veja os detalhes completos em CONTRIBUTING.md, o nosso Código de Conduta e as issues marcadas com boa primeira contribuição no GitHub.
